# Benchmark Close-Out Template
**Short Record for Closing a Benchmark Stream**
Version: 2026-03-28

---

## Purpose

Use this template when a benchmark stream is ready to be closed.

A benchmark stream should be closed when:
- it is materially satisfied
- it is intentionally paused/deferred
- or it is no longer the right next investment

This template records the final decision and the reason for closure.
