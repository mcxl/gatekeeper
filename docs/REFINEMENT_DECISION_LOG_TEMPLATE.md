# Refinement Decision Log Template
**Per-Cycle LBV Decision Record**
Version: 2026-03-28

---

## Purpose

Use this template to record one completed LBV refinement cycle.

It is intended to capture:
- what benchmark case was used
- what weakness was targeted
- what refinement was applied
- what changed
- what decision was made at the end of the cycle

This is the minimum useful record for one benchmark-driven improvement pass.
