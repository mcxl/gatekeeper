# Safe Method SWMS Review Engine
**First Benchmark Asset Checklist**
Version: 2026-03-28

---

## Purpose

Use this checklist before moving the SWMS Review Engine benchmark stream from:

`HOLD`

to:

`ACTIVE`

The goal is to make sure the first benchmark cycle has the minimum useful asset set.

---

## Minimum Asset Set

### 1. Principal-contractor project risk register

- [ ] One real project risk register selected
- [ ] Format available in `.xlsx` or another clearly parseable source
- [ ] Risk items are readable enough to identify:
  - hazard descriptions
  - required controls
  - hold points if any
  - HRCW expectations if any

### 2. Subcontractor SWMS

- [ ] One real subcontractor SWMS selected
- [ ] Format available in `.docx` or another clearly parseable source
- [ ] SWMS is for the same project or same project risk context as the risk register

### 3. Human benchmark expectation

- [ ] One short benchmark note exists stating:
  - what should align
  - what should fail or show gaps
  - what a principal contractor reviewer would expect to see

This does not need to be long.
It just needs to give the benchmark cycle a real quality target.

---

## Quality Check Before Activation

- [ ] The risk register is project-specific, not just a generic corporate template
- [ ] The SWMS is specific enough to review meaningfully
- [ ] The pair is suitable for comparison
- [ ] The benchmark is about review/gap detection, not final approval automation

---

## Activation Rule

Move the benchmark stream to `ACTIVE` only when:
- one real PC risk register exists
- one real subcontractor SWMS exists
- one benchmark expectation note exists
- comparison result contract is clear enough to test

If any of those are missing, keep the stream at `HOLD`.

---

## First Benchmark Goal

The first benchmark cycle should answer:

**Can Safe Method produce a useful gap report that helps a principal contractor review a subcontractor SWMS against project risk requirements?**
