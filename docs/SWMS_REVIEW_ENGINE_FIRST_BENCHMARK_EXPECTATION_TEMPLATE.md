# Safe Method SWMS Review Engine
**First Benchmark Expectation Note Template**
Version: 2026-03-28

---

## Purpose

Use this template to define the human benchmark expectation for the first SWMS Review Engine benchmark pair.

This note should describe, in plain English:
- what should align
- what should show gaps
- what a principal contractor reviewer would expect the engine to find

It does not need to be long.
It just needs to give the benchmark cycle a clear quality target.
